# Studio Giu Oliveira Tattoo — proposta de página

Página estática (HTML, CSS e JS puros, sem build) desenvolvida por Aquiles Soares.

- Tudo o que é publicado fica em `public/` (`index.html`, `og.png`, `favicon.svg`).
- Publicação na Cloudflare (Workers com assets estáticos) pelo `wrangler.jsonc`: sem comando de build, deploy com `npx wrangler deploy`.
- Textos entre colchetes, fotos e valores são provisórios até a aprovação da cliente.
